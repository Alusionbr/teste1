        Busca de vídeos no YouTube

        A busca funciona sem chave, por serviços públicos de busca (o texto que você digita vai para eles). Com uma chave gratuita da API do YouTube (cerca de 100 buscas por dia) a busca usa o próprio YouTube e mostra só vídeos que podem tocar aqui. A chave fica só neste aparelho. Se a busca não responder, use “Procurar no YouTube” e cole o link.

        Backup

        Tudo fica guardado neste aparelho (inclusive o placar do Cantar sozinho). Exporte de vez em quando. Os áudios escolhidos do aparelho não vão no backup.
