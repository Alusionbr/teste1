# Quintal do Tesouro — versão web

Jogo de aventura em 2D feito para teclado, controle e tela sensível ao toque.

- **Jogar:** abra `https://alusionbr.github.io/teste1/quintal-do-tesouro/`.
- **Celular/tablet:** use na horizontal; os botões aparecem em aparelhos com toque. O navegador guarda o progresso neste aparelho.
- **Computador:** setas ou WASD para andar; Espaço para pular; J para cavar; K para dinamite; L para a raposa; Esc para pausar.
- **Recomeçar:** o jogo pede confirmação e guarda uma cópia do save antes de zerar.

A versão web vem do projeto local `Quintal do Tesouro`. O jogo publicado usa arte original do projeto, modo Aventureiro e salva o progresso no armazenamento do navegador. O progresso da versão web é separado do jogo instalado no computador.

## Compatibilidade

É necessário um navegador atual com WebAssembly e WebGL 2.0. Não foi testado em todos os aparelhos nem com controle físico. Em celulares, use a orientação horizontal e espere o carregamento inicial dos recursos.
