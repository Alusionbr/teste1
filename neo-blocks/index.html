COMO JOGAR

Organize as peças que caem para completar linhas horizontais. Cada linha completa desaparece e libera espaço.

Celular: use os seis botões abaixo do tabuleiro. Mantenha as setas pressionadas para repetir o movimento.

PC: setas para mover, cima para girar, espaço para soltar, C para reservar e P para pausar.

Modos: Clássico (pontuação); Tempo (2 minutos); Turbo (aceleração a cada 20s); Sobrevivência (obstáculos periódicos); Puzzle (limpar 4 linhas com até 8 peças); Laboratório (poder de limpar a linha inferior com tecla X ou botão); Gravidade (velocidade oscilante); Zen (sem derrota).

Rotação com pequenos ajustes de posição; sistema de 7 peças por pacote; visualização de sombra e reserva por turno. Os efeitos sonoros ficam ligados quando você inicia uma partida; a música é opcional e pode ser ativada no topo. Alguns navegadores liberam o áudio apenas depois de tocar em Jogar.
